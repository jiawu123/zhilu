# 前端交互更新 · 2026-09-15

本次仅修改 apps/web 和本说明。后端、数据库、模型接口、知乎接口和认证校验不变。

## 已实现

- 修正访谈进度区域的“跳过全部剩余问题”布局，支持桌面、平板、手机。
- Logo 的“路”主笔画约减细 4%；网页 favicon 与品牌旁的小图标使用透明刘看山 PNG。本体外背景透明。
- 已完成任务使用绿色边线、浅绿色背景、勾选标记、“已完成”文字和标题划线，与未完成任务区分。
- 时间轴固定在屏幕底部，一次显示从首个任务日期至最后截止日期之间的所有每日刻度。按实际日历间隔排布，含没有任务的日期；日期文字按可用宽度避让，首尾日期始终显示。指针随选择或画布位置更新。
- 点击时间轴以固定 300 毫秒动画平滑移动画布，与距离无关；连续点击从当前位置转向新目标，手动滚动可中止动画。系统开启“减少动态效果”时直接定位。
- 计划调整位于时间轴上方；同一个外框连续从胶囊变成输入框，文字与控件同时渐显。收起保留输入，任务或连线入口可重新展开。快速反向操作从当前形状继续，不替换外框节点。
- 连线加号和图标几何居中。“↔”点击可打开日期编辑，原有拖动及方向键按周调整继续保留。
- 项目信息及任务详情面板从实际点击坐标展开并收回；键盘操作使用触发控件中心。保留原生模态、焦点返回、Escape 和未保存修改确认。
- “我的目标”列出已创建项目与未关联项目的背景登记，可切换项目或新建目标，原历史记录仍可访问。
- 新增退出入口和登录预留页，使用既有 `/api/auth/logout`。当前服务为本地工作区，因此显示“退出工作区”和“进入本地工作区”；知乎登录仍以服务的现有认证配置为准。
- 登录页按用户参考图采用白色表单、左右分栏、蓝色圆球及磨砂玻璃布局。保留现有内容、文案和功能；手机使用单列表单。
- 通用控件增加点击、选择、键盘和焦点微动画。等待过程展示实际已收到的步骤、等待时长、动态指示与骨架；不模拟完成百分比。
- 新生成并确认应用的方案：任务卡从小圆形展开，连线从左到右生长；总时长 `min(7000, max(2000, 任务数 × 140 + 600))` 毫秒。
- 从“我的目标”进入项目：整段入场动画固定 1000 毫秒，与任务数量无关。普通状态保存不会重播。系统开启“减少动态效果”时停用动画。
