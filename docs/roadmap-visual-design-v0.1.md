# Roadmap 视觉方案 v0.1：会呼吸的路线星图

## 核心判断

用户打开产品时只需要回答一个问题：**我现在在路线的哪里，下一步要做什么？**

因此首屏不展示完整导航、History、表单和证据列表。它们仍然存在，但只在用户主动点击后出现。Roadmap 图占据整个可用画布。

## 图的视觉隐喻

- 一条弯曲主路径代表 Current Path，而不是普通表格或项目管理看板；
- Milestone 是路径上的“区域”，使用大号序号和淡色光晕划分阶段；
- Task 是可点击的“路标节点”，默认只显示状态、名称和工时；
- 已完成路径变亮，待执行路径保持低对比度；当前节点持续轻微呼吸；
- 路径上有缓慢移动的光点，让计划看起来处于运行状态；
- Event 发生后，受影响路径变为橙色脉冲；未受影响区域保持安静；
- 终点使用目标光环，始终提醒用户这张图为什么存在。

## 信息层级

### 首屏常驻

1. 左上角产品入口，用于 toggle Sidebar；
2. 中间一行当前目标；
3. 画布中的 Roadmap；
4. 右上角一个“记录变化”入口；
5. 左下角一句操作提示。

### 点击后出现

- 点击产品入口：左侧抽屉显示进度、每周投入、History 和新增任务；
- 点击节点：右侧抽屉显示编辑、产出、完成标准和依据；
- 点击记录变化：Event 弹层；
- 产生 Patch：底部 Impact Review 浮层。

## 动效约束

- 动效用于表达状态，不做纯装饰性粒子雨；
- 主路径光点缓慢移动，节点 hover 上浮，当前节点呼吸；
- 打开抽屉时画布不跳页，只轻微让位；
- Impact 只让受影响节点和路径闪烁，避免全屏报警；
- 遵循 `prefers-reduced-motion`，用户关闭系统动效后停止循环动画。

## P0 边界

- P0 使用同一份 Plan Data 投影路线星图，不新增第二套图数据；
- 首版支持点击、编辑、状态更新和 Impact 高亮；
- P0 首版支持水平拖动任务按整周改期，并把新日期作为用户直接修改提交给 Plan Engine；画布支持有限范围平移和一键复位，缩放仍后置；
- 图形布局是可替换投影，Plan Engine 和 Bundle Schema 不依赖坐标。
