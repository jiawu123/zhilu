# Web

Roadmap Workspace 前端。只通过本地 API 和共享 `contracts` 访问产品状态。

入口按 `?project=<id>&page=interview|plan|roadmap` 区分三个页面。无项目参数默认进入访谈；未确认计划的项目即使直接访问 Roadmap 地址，也会展示计划确认页。

支持导入已有 Markdown/TXT 作为背景。访谈由服务端模型根据目标每批生成 1–5 道题，自行选择单选、多选、填空或程度 toggle，每轮提交累计问答后再生成下一批，最多 30 题。最后一批可以少于 5 题。填空题全程最多 3 道（跳过仍计入）；每题可跳过，选中“其他”需填写补充文本。进度条展示已回答/跳过数量和 30 题上限，信息充分可提前结束。请求等待时展示旋转圆及等待秒数，失败、断连、超时显示具体错误并保留当前选择。访谈完成后可编辑背景、时间、目标、成功标准和取舍；确认后进入计划页并自动发起知乎研究。当前标签页通过 sessionStorage 保存会话 ID，刷新从服务端恢复批次。

独立计划页展示候选路线、推荐理由、任务、验收和证据，右侧对话框调用模型调整草稿。调整复用已有证据，不自动确认；只有点击“确认计划，生成路线图 / Plan Bundle”才保存正式 Baseline 并进入 Roadmap。Mock 演示保留独立标识且不支持真实模型对话调整。

Roadmap 支持本周焦点、节点编辑/拖动/完成/新增/归档、依据检查器、Event、Impact Diff、History，以及 JSON、Markdown、`.planbundle.zip` 导出。

时间约束事件先显示规则预演，明确说明任务日期未调整；用户可点击“用 AI 重新排期”。底部 Dock 默认紧凑，展开后逐项查看真实 Before → After、判断依据和提醒，确认时整组应用而非逐项批准。过期预演不可应用，模型失败保留原方案；History 中可展开查看处理记录。其他事件仍只记录影响，不冒充已完成重规划。

超过 8 个任务时，路线图使用四条轨道和可横向拖动的宽画布，保持卡片字号；可拖到末尾或点击“回到起点”。每周复盘与待确认假设收在侧栏的折叠区，也可打开详情检查。

账号入口由 `AccountApp` 提供。未配置 OAuth 时使用本地工作区；配置后展示知乎登录页，只有取得服务端会话后才加载用户数据。路线背包底部集中提供“历史记录”“修改记录”“带走这张路线”三个弹窗入口，不再显示底部账号栏。“历史记录”可查看全部访谈、逐题回答及提交/生成记录，继续未完成访谈，或打开关联计划、版本历史和确认前调整对话。访谈支持草稿自动保存、刷新恢复，以及已提交回答后的独立生成重试。历史保存在后端磁盘，清理浏览器 sessionStorage 不会删除历史；OAuth 账号与旧本地数据分开。
