# Web

Roadmap Workspace 前端。只通过本地 API 和共享 `contracts` 访问产品状态。

已实现动态目标访谈、条件化追问、User Context / Goal Contract 确认、Markdown/TXT 背景导入、路线星图、本周焦点、节点选择与编辑/拖动/完成/新增/归档、依据检查器、节点级与时间约束 Event、Impact Diff 审批、History，以及 JSON、Markdown、`.planbundle.zip` 导出。路线星图支持画布平移与复位；任务使用 Pointer Drag 实时跟手，松手后按整周改期，日期变化会反映到横向坐标。研究准备版在图上只显示一个下一步入口；用户可优先运行真实知乎研究，也可退回明确标记的 Mock 演示。路线比较、Roadmapper 预览与 Baseline 确认收在单个研究弹层中。当前真实 Route 是证据驱动的确定性草案；模型驱动的 Roadmapper 与 Event 自动排期仍待接入。
