# Web

Roadmap Workspace 前端。只通过本地 API 和共享 `contracts` 访问产品状态。

已实现动态目标访谈、条件化追问、User Context / Goal Contract 确认、Markdown/TXT 背景导入、路线星图、本周焦点、节点选择与编辑/拖动/完成/新增/归档、依据检查器、节点级与时间约束 Event、Impact Diff 审批、History，以及 JSON、Markdown、`.planbundle.zip` 导出。路线星图支持画布平移与复位；任务使用 Pointer Drag 实时跟手，松手后按整周改期，日期变化会反映到横向坐标。研究准备版在图上只显示一个下一步入口；用户可优先运行真实知乎研究，也可退回明确标记的 Mock 演示。

模型路线比较、推荐理由、证据引用和 Baseline 确认收在同一弹层；风险、验收条件和来源默认折叠。按周任务显示日期与工时，用户可核查证据适用条件、局限和采用原因。只有存在 Roadmapper 运行记录时才标为模型草案，旧规则结果及 Mock 保持各自标记。M4 Event 的模型局部排期仍待接入。

超过 8 个任务时，路线图使用四条轨道和可横向拖动的宽画布，保持卡片字号；可拖到末尾或点击“回到起点”。每周复盘与待确认假设收在侧栏的折叠区，也可打开详情检查。
